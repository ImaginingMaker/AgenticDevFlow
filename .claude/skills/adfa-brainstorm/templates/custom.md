# adfa-brainstorm 特有配置

## 发散参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 快闪模式最大想法数 | 20 | 快闪模式下达到此数自动询问收敛 |
| 标准模式最大想法数 | 40 | 标准模式下达到此数自动询问收敛 |
| 深度模式最大想法数 | 60 | 深度模式下达到此数自动询问收敛 |
| 能量检查点间隔 | 4 | 每 N 轮对话进行一次能量检查 |
| 正交维度切换阈值 | 8 | 每 N 个想法后强制切换正交领域 |

## 输出路径

| 模式 | 输出位置 |
|------|---------|
| 敏捷模式（独立调用） | 当前工作目录 / 对话上下文 |
| 工程模式（harness 调度） | `docs/workflows/{任务ID}/brainstorm.md` |

## 快速模式契约

下游技能调用快速模式时，应在 prompt 中传递以下参数：

```yaml
mode: quick
focus_area: "<聚焦方向>"          # 如"登录页交互方案"
max_rounds: 3                     # 最大发散轮数
output_format: "top3 + idea_list" # 输出结构
caller: "<调用方技能名>"           # 如 adfp-requirement-analyzer
```
