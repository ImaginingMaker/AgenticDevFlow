- 链路拆解粒度：粗粒度（阶段级）/ 细粒度（任务级）
- 任务预估工时单位：天 / 小时

- 框架优先：React 18 + TypeScript 5（示例，可按项目调整）
- UI 库优先：Ant Design / MUI / shadcn/ui / 无（选择其一）
- 目标平台：Web / H5 / 小程序 / 桌面端（多选）

## 报告偏好
- 是否包含竞品参考：是 / 否
- 是否包含技术选型对比：是 / 否
