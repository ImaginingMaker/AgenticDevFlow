# adfa-code-context 特有配置

## 追踪参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 追踪深度 | 2-3 层 | 递归追踪内部引用的最大层数 |
| 关键路径上限 | 10 个模块 | 超过此数量时截断并标注 |
| 文件大小阈值 | 500 行 | 超过此行数的文件使用分段读取 |
| 忽略模式 | `node_modules/`, `dist/`, `.git/` | 不追踪的外部目录 |

## 入口检测优先级

1. `index.ts` / `index.tsx` / `index.js`
2. `main.ts` / `main.tsx` / `App.tsx`
3. `package.json` → `main` 字段指向的文件
4. 文件夹中唯一的顶层文件

## 输出偏好

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 报告语言 | 中文 | 输出报告的语言 |
| 流程图样式 | 树形文本 | 调用链使用 ASCII 树形图 |
| 模块描述长度 | 1-2 句 | 每个模块描述的最长限制 |
