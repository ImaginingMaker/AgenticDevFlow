# 引导与收敛流程

> 由 `adfa-brainstorm` SKILL.md 按需加载的交互引导和收敛流程。

---

## 想法格式模板

每个想法使用结构化格式：

```
[#N] <助记标题>
💡 <核心概念：1-2句>
⚡ <新颖点：与显而易见方案的不同>
```

## 交互引导模式

### 教练式引导（而非问答）

```
✅ 正确模式：
"这个想法很有趣！让我延伸一下...如果再加上 [X]，会不会变成 [Y]？"

❌ 错误模式：
"请列出3个可能的解决方案。"
```

### 能量检查点（每4-5轮对话）
```
"我们已经生成了 [X] 个想法！
能量检查：继续深入？切换技术？还是充分了？"
```

### 深挖模式
```
"这个很棒！让我深入挖掘：
- 在实践中有哪些变体？
- 什么让它与常规方案不同？
- 如果做到极致会是什么样？"
```

### 鼻子引导（用户卡住时）
```
"如果完全不考虑可行性，最理想是什么？
如果只考虑最低成本，能做什么？
有没有你一直在回避的'疯狂想法'？说出来看看..."
```

---

## 收敛阶段

### 触发条件
- 达到 30+ 想法
- 用户说"差不多了"/"够了"
- 时间预算将用尽
- 用户能量明显下降

### 收敛流程

1. **主题聚类**：将想法按主题分组
2. **快速投票**：基于目标选出 Top 3（影响力/可实现性/创新性）
3. **行动建议**：每个 Top 3 的下一步、资源、障碍、成功指标

---

## 失败模式预警

| 信号 | 调整 |
|------|------|
| 用户频繁说"不知道" | 切换更刺激的技术（随机词、反向思考） |
| 想法都类似/语义聚类 | 强制切换正交维度（技术→情感→商业） |
| 用户被动等待 | 主动抛出延伸 |
| 想法全是显而易见 | 挑战："现在给我一个会让你说'这太疯狂了'的想法" |

## 输出格式

### 产物模板
```markdown
# 头脑风暴：<主题>
日期：YYYY-MM-DD HH:mm
模式：快闪/标准/深度
技术使用：[技术列表]

## 想法清单
[#1] <标题> | [#2] <标题> | ...

## 主题聚类
| 主题 | 想法编号 | 核心洞察 |
|------|----------|----------|

## Top 3
| 排名 | 想法 | 选择理由 | 下一步 |
|------|------|----------|--------|

## 会话洞察
```

### 快速模式返回值（JSON，供下游技能消费）
```json
{
  "mode": "quick",
  "topic": "<主题>",
  "top3": [{ "rank": 1, "title": "...", "concept": "...", "rationale": "..." }],
  "idea_list": [{ "id": 1, "title": "...", "concept": "...", "novelty": "..." }]
}
```
