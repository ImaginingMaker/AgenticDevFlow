# Wiki目录结构规范

## 根目录结构（固定）

项目根目录下的Wiki存放路径及顶层目录结构，严格遵循以下格式：

```
项目根目录/
└── docs/
    └── wiki/                  # 所有Wiki相关内容统一存放此处
        ├── 总目录.md          # Wiki总索引，自动更新
        ├── 技能说明.md        # 技能设计原理、使用规范
        ├── assets/            # 图示存放目录
        │   ├── 第一章/
        │   ├── 第二章/
        │   └── 各页面图示/
        └── 业务模块目录/
            ├── 模块1/
            │   ├── 页面1/
            │   │   ├── index.md
            │   │   └── assets/
            │   └── 页面2/
            │       ├── index.md
            │       └── assets/
            └── 模块2/
```

## 页面Wiki章节结构（8大章节）

每个页面的Wiki主文档（index.md）包含以下固定章节：

### 第一章 页面基础信息
- 1.1 页面标识（路由名称、文件路径）
- 1.2 功能简介（核心功能描述）
- 1.3 技术栈说明（框架、库、版本）
- 1.4 关联页面/依赖关系

### 第二章 路由与入口链路
- 2.1 完整路由链（从根路由到当前页面）
- 2.2 入口触发流程（如何进入页面）
- 2.3 入参说明（路由参数、查询参数）
- 2.4 前置依赖（权限要求、前置操作）

### 第三章 核心业务链路（重点）
- 3.1 初始化加载链路
- 3.2 主流程操作链路
- 3.3 分支跳转链路
- 3.4 弹窗/抽屉次级链路
- 3.5 链路依赖关系图示

### 第四章 组件结构与依赖
- 4.1 组件树结构（图文）
- 4.2 组件分类（自定义/公共/业务）
- 4.3 Props/事件说明
- 4.4 组件渲染逻辑

### 第五章 数据流与状态管理
- 5.1 全局状态使用说明
- 5.2 局部状态定义
- 5.3 数据流转流程（图文）
- 5.4 数据缓存规则

### 第六章 接口请求规范
- 6.1 接口列表（表格）
- 6.2 接口调用时机
- 6.3 接口依赖顺序
- 6.4 入参/出参详细说明

### 第七章 权限、埋点与异常处理
- 7.1 权限控制逻辑
- 7.2 埋点事件说明
- 7.3 异常捕获与处理
- 7.4 容错降级方案

### 第八章 维护与变更记录
- 8.1 版本迭代记录
- 8.2 链路/代码修改记录
- 8.3 注意事项（坑点/兼容问题）
- 8.4 后续优化建议

## 命名规范

### 文件夹命名
- 格式：小写字母+连字符
- 示例：user-management, user-list
- 禁止：中文、大写字母、特殊符号

### 文件命名
- Wiki主文档：index.md
- 图示文件：章节-内容-序号.png
- 示例：3-1-初始化链路图.png

### 章节命名
- 格式：序号.层级
- 示例：3.2.1 表单提交操作
- 禁止修改章节序号和核心名称
