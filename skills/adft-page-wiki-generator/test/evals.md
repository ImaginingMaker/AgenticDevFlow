# adft-page-wiki-generator - 评估用例

## 核心场景
| # | 场景描述 | 预期行为 | 验证方式 |
|---|---------|---------|---------|
| 1 | 单页面解析：解析 src/views/user/list.vue 页面，生成Wiki文档并同步至 docs/wiki 目录 | 生成包含8大章节的标准化Wiki文档，存放于 docs/wiki/user-management/user-list/index.md | 手动 |
| 2 | 批量生成：分析 src/views/order 下所有页面，批量生成Wiki文档 | 遍历目录下所有页面文件，为每个页面生成Wiki，存放于 docs/wiki/order-management/ 对应子目录 | 手动 |
| 3 | React 组件：为 React 组件 src/pages/Dashboard.tsx 生成关键链路分析文档 | 识别初始化链路、业务操作链路、异常处理链路，生成结构化Wiki文档 | 手动 |

## 边界测试
| # | 边界情况 | 预期处理 |
|---|---------|---------|
| 1 | 目标文件不存在 | 提示用户文件路径无效 |
| 2 | 空目录批量生成 | 提示无页面文件，跳过 |
| 3 | 非标准目录结构 | 尝试自适应，标注无法识别部分 |
