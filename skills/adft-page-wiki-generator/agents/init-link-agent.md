# 初始化链路分析 SubAgent

## 任务目标
分析页面初始化加载链路，生成标准化文档。

## 输入信息

### 项目上下文（从文档提取）
- 项目名称：{projectName}
- 技术栈：{techStack}
- 目录结构：{structure}
- 开发规范：{conventions}

### 页面信息
- 页面文件路径：{filePath}
- 生命周期代码片段：{lifecycleCode}
- 初始化请求函数：{initRequests}

## 分析步骤

### 1. 识别生命周期钩子
查找以下代码模式：
- Vue: `onMounted`, `onCreated`, `mounted()`, `created()`
- React: `useEffect(() => {}, [])`, `useLayoutEffect`

### 2. 追踪初始化请求
识别钩子内调用的接口函数：
- 函数名称
- 请求参数来源
- 返回数据处理逻辑

### 3. 梳理数据流转
追踪数据从请求到渲染的完整路径：
- 接口返回 → 状态赋值 → 组件渲染

### 4. 识别依赖关系
分析初始化链路的依赖：
- 前置条件（权限、参数）
- 依赖的其他接口
- 依赖的全局状态

## 输出格式

```markdown
### 3.1 初始化加载链路

**链路名称**：页面初始化加载

**触发条件**：
- 用户进入页面
- 路由参数变化时重新加载

**执行步骤**：
1. 组件挂载，触发 onMounted 钩子
2. 调用 getUserList 接口，传入默认分页参数
3. 接口返回数据，赋值给 tableData 状态
4. 表格组件接收数据，触发重新渲染

**数据流转**：
| 阶段 | 数据状态 | 说明 |
|------|----------|------|
| 初始 | tableData = [] | 空数组，显示加载状态 |
| 请求中 | loading = true | 显示 loading 动画 |
| 请求成功 | tableData = [...] | 显示数据列表 |
| 请求失败 | error = message | 显示错误提示 |

**依赖关系**：
- 前置权限：user:view
- 依赖接口：getUserList
- 依赖状态：无

**异常处理**：
- 接口超时：显示超时提示，提供重试按钮
- 权限不足：跳转到 403 页面
```

## 注意事项
- 必须追踪完整的调用链，不能遗漏中间步骤
- 区分同步操作和异步操作
- 标注每个步骤的代码位置（文件:行号）
