# adfo-task-orchestrator

> 入口页。详细的任务调度流程见 `references/scheduling-flow.md`。

**定位**：基础设施层技能。接收任务清单 → 构建 DAG → 调度执行 → 汇总结果。
**不做**：需求解析、任务拆解、角色定义。

---

## 输入协议

调用方发送任务清单（表格：ID / 描述 / Agent类型 / 提示词 / 依赖）+ 可选执行参数（最大并发数、超时、失败策略）。

## 核心流程概览

```
解析清单 → 校验(唯一ID/无循环依赖) → 构建DAG → 识别并发组 → 按组顺序调度 → 汇总结果
```

| 步骤 | 说明 |
|------|------|
| 构建 DAG | 按依赖关系构建有向无环图 |
| 并发组 | 同一拓扑层级无依赖的任务并行执行 |
| 上下文传递 | 串行链路中下游 prompt 自动拼接上游结果 |

---

## 失败处理

| 策略 | 行为 |
|------|------|
| continue（默认） | 标记阻塞下游，继续无依赖任务 |
| abort | 单任务失败立即停止所有 |
| retry | 失败后重试最多 N 次 |

---

## 输出

任务执行报告：执行概览 → DAG 拓扑 → 各并发组详情 → 各任务输出 → 冲突与发现。

---

## 职责边界

| 技能 | 边界 |
|------|------|
| adfo-harness-runner | 阶段级流水线管理，task-orchestrator 做**阶段内并发调度** |
| 各调用方 SKILL | 调用方负责"做什么"（任务规划+prompt），task-orchestrator 负责"怎么做"（DAG+调度+汇总） |

## 约束规则

1. 不解析需求：任务清单由调用方提供
2. 不定义角色：SubAgent 类型由调用方指定
3. 最大并发控制：单组上限默认 4
4. 检测到循环依赖时拒绝执行
5. 上下文最小化：只传递必要的前序结果
6. 超时保护：单任务 + 总超时双重保护

## 模板注入

`templates/custom.md` — 本技能特有的执行参数默认值（并发上限、超时、失败策略）。
