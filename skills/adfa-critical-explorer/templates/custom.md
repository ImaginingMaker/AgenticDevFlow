# adfa-critical-explorer 特有配置

## SubAgent 执行参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 并发数 | 6 | 固定 6 个 SubAgent 同时启动 |
| 单 SubAgent 超时 | 120s | 单个 SubAgent 最大执行时间 |
| 汇总超时 | 300s | 主 Agent 等待所有 SubAgent 的总超时 |
| 模型选择 | 继承主会话 | SubAgent 默认使用与主 Agent 相同的模型 |

## 输出偏好

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 报告语言 | 中文 | 输出报告的语言 |
| 风险排序 | 优先级排序 | 高风险项排在前面 |
| 预设标注 | 启用 | 模糊需求自动补充预设并标注 |

## 平台感知配置

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 默认框架 | 自动检测 | 自动从 techStack 检测，失败时回退为通用路径 |
| 框架提示 | 启用 | 检测到未知框架时提示用户指定 |
| 框架细则路径 | references/critical-dimensions.md | 框架特定批判性审查细则文件路径 |

## 二次触发

用户可通过以下方式指定单个 SubAgent 深度挖掘：
- "让 SubAgent N 再深入分析"
- "重点看架构维度"
- "重新评审交互体验部分"

框架感知的二次触发额外支持：
- "按 Vue 的方式再看一遍"
- "从跨端角度重新评审"
