# 重构自定义配置

## 从 state.json 加载（工程模式）

当被 `adfo-harness-runner` 调度时，以下值从 `state.json.techStack` 读取，覆盖本配置。

## 本技能特有配置

### 重构风格
- 默认方向：精简重构 / 极致拆分 / 兼容原有逻辑
- 组件最大行数：{默认 200}
- 逻辑单元命名约定：`{prefix + Name}`（React/Vue 以 `use` 开头，小程序遵循 Behavior 命名）

### 代码风格
- 类型定义：interface / type（框架通用）
- 导出方式：named export / default export

### 重构阈值
- 单文件超过 {默认 200} 行 → 建议拆分
- 独立状态变量超过 {默认 5} 个 → 建议收敛
- 嵌套层级超过 {默认 3} 层 → 建议早返回或组件化

### 框架映射覆盖
- 用户可覆盖检测到的框架映射（如：React 项目中指定某个子模块按小程序模式重构）
- 格式：`框架映射覆盖: { 路径模式: 目标框架 }`
