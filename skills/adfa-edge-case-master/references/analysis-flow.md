# 5 边界维度并行分析任务清单

> 供 `adfa-edge-case-master` 使用。5 个边界维度通过 `adfo-task-orchestrator` 并发执行的分析任务。

## 总体执行流

```
分析输入 → 并发 5 边界维度 → 合并去重 → 生成测试矩阵 → 生成代码 → 输出报告
```

## 调度方式

通过 `adfo-task-orchestrator` 并发调度（全部无依赖，最大并发 5）。

---

## 维度 1：输入边界分析

### 职责
识别函数/API 的输入参数边界条件。

### 分析任务

```
对目标函数/组件的每个输入参数，检查：
□ 最小值（数值）/ 最短长度（字符串）
□ 最大值（数值）/ 最长长度（字符串）
□ 空值（空字符串、空数组、空对象）
□ null / undefined
□ 类型错误（数字传字符串、对象传数组）
□ 特殊值（NaN、Infinity、0、-0）
□ 格式不匹配（邮箱格式错误、日期格式错误）
□ 枚举之外的值（超出允许值集合）
```

### 输出格式

```markdown
### 输入边界分析结果

| 参数 | 类型 | 边界条件 | 生成用例数 |
|------|------|---------|-----------|
| {name} | string | 空串、null、超长、特殊字符 | 6 |
| {name} | number | 0、负值、NaN、最大值 | 5 |
```

## 维度 2：业务边界分析

### 职责
识别业务规则限制和状态转换边界。

### 分析任务

```
对目标功能的业务逻辑，检查：
□ 状态机所有合法转换
□ 状态机所有非法转换（边界禁区）
□ 业务规则阈值（折扣门槛、满减条件）
□ 权限边界（游客→登录用户→管理员）
□ 数据量边界（单页条数、选择上限、上传大小）
□ 时间边界（有效期、截止日期、跨天/跨月/跨年）
□ 并发边界（同时操作、竞态条件）
```

### 输出格式

```markdown
### 业务边界分析结果

| 业务规则 | 边界条件 | 生成用例数 |
|---------|---------|-----------|
| 状态转换 | {状态A}→{状态B} 合法/非法 | 4 |
| 业务阈值 | {条件}达到/未达到阈值 | 3 |
```

## 维度 3：异常场景分析

### 职责
识别所有可能的异常路径。

### 分析任务

```
对目标功能的执行路径，检查：
□ 网络异常（超时、断开、弱网）
□ HTTP 异常（4xx、5xx、重定向）
□ 数据异常（空响应、格式错误、字段缺失）
□ 资源不存在（404、已删除、已过期）
□ 权限不足（未登录、无权限、被限制）
□ 依赖异常（第三方服务挂了、数据库不可用）
□ 操作顺序异常（未登录先操作、未保存就提交）
□ 文件异常（大小超限、格式不支持、损坏）
□ 并发冲突（多人同时编辑、重复提交）
```

### 输出格式

```markdown
### 异常场景分析结果

| 异常类型 | 具体场景 | 预期行为 | 用例数 |
|---------|---------|---------|-------|
| 网络异常 | 请求超时 > 5s | 显示重试提示 | 1 |
| 权限不足 | 游客访问需登录页面 | 跳转登录 | 1 |
```

## 维度 4：性能边界分析

### 职责
识别性能瓶颈和压力边界。

### 分析任务

```
对目标功能，检查：
□ 数据量边界（1条、100条、1000条、10000条）
□ 频繁操作（快速点击、短时间高频触发）
□ 大量并发（同时发 N 个请求）
□ 资源开销（大图片、长列表、复杂计算）
□ 时间维度（长时间运行、内存泄漏检查）
□ 重渲染边界（大数据量列表渲染、复杂表单）
□ 缓存边界（缓存过期、缓存击穿、缓存穿透）
□ 节流/防抖边界（极限触发频率）
```

### 输出格式

```markdown
### 性能边界分析结果

| 性能维度 | 边界场景 | 预期性能目标 | 用例数 |
|---------|---------|------------|-------|
| 数据量 | 渲染 10000 条列表 | 首屏 < 500ms | 2 |
| 频繁操作 | 1s 内点击 100 次 | 只执行 1 次 | 2 |
```

## 维度 5：安全边界分析

### 职责
识别安全漏洞和攻击面。

### 分析任务

```
对目标功能，检查：
□ XSS 注入（script、onerror、href="javascript:"）
□ 命令注入（shell 命令拼接）
□ SQL 注入（拼查询字符串）
□ 路径遍历（../ 绕过目录限制）
□ 越权访问（修改 URL 参数访问他人数据）
□ CSRF（跨站请求伪造）
□ 敏感信息泄露（Token 暴露、日志输出密钥）
□ 输入校验绕过（特殊编码、Unicode 混淆）
□ 文件上传（危险文件类型、文件名注入、大小超限）
```

### 输出格式

```markdown
### 安全边界分析结果

| 安全类型 | 攻击向量 | 预期防御 | 用例数 |
|---------|---------|---------|-------|
| XSS | <script>、<img onerror> | 转义输出 | 4 |
| 越权 | 修改 user_id 参数访问他人数据 | 服务端二次校验 | 2 |
```

## 合并去重规则

5 个维度分析完成后，按以下规则合并：

| 情况 | 处理 |
|------|------|
| 同一用例出现在多个维度 | 只保留一条，标注多维度属性 |
| 冲突的预期行为 | 以异常场景和安全边界为准 |
| 重复的 P0 用例 | 按 P0 → P1 → P2 排序去重 |

### 优先级排序

| 优先级 | 类型 | 说明 |
|--------|------|------|
| P0 | Happy Path + Critical Edge | 必须覆盖 |
| P1 | Alternative Path + Common Edge | 建议覆盖 |
| P2 | Error Path + Rare Edge | 可选 |

### 生成测试矩阵

```markdown
## 测试用例矩阵

| # | 维度 | 场景 | 输入 | 预期 | 优先级 |
|---|------|------|------|------|--------|
| TC1 | 输入边界 | 空字符串 | "" | 返回 false | P0 |
| TC2 | 业务边界 | 状态转换异常 | suspended→deleted | 返回 false | P0 |
| TC3 | 异常场景 | 网络超时 | 超时 > 5s | 显示重试 | P1 |
```
